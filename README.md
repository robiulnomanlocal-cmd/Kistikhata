# কিস্তি খাতা — Android অ্যাপ

কিস্তিতে ফোন বিক্রির হিসাব রাখার অ্যাপ। ইন্টারনেট ছাড়াই চলে, সব তথ্য ফোনেই থাকে।

## APK বানানোর উপায় ১: Android Studio (কম্পিউটারে)

1. https://developer.android.com/studio থেকে Android Studio ইনস্টল করুন।
2. এই ZIP ফাইল আনজিপ করুন।
3. Android Studio → **Open** → `KistiKhata` ফোল্ডার বাছুন। প্রথমবার কিছুক্ষণ ডাউনলোড চলবে (ইন্টারনেট লাগবে)।
4. মেনু থেকে **Build → Build App Bundle(s) / APK(s) → Build APK(s)**।
5. শেষ হলে **locate** চাপুন। `app/build/outputs/apk/debug/app-debug.apk` ফাইলটা পাবেন।
6. ফাইলটা ফোনে পাঠিয়ে খুলুন। "Unknown apps / অজানা উৎস" অনুমতি চাইলে দিন, তারপর Install।

## APK বানানোর উপায় ২: GitHub (কম্পিউটারে কিছু ইনস্টল না করে)

1. github.com এ একটা অ্যাকাউন্ট খুলে নতুন repository বানান।
2. এই ফোল্ডারের সব ফাইল (লুকানো `.github` ফোল্ডারসহ) আপলোড করুন।
3. **Actions** ট্যাবে গিয়ে "Build APK" চলা শেষ হওয়া পর্যন্ত অপেক্ষা করুন (৫–১০ মিনিট)।
4. সেই রানের নিচে **KistiKhata-apk** ডাউনলোড করুন, ZIP খুললে APK পাবেন।

## জরুরি: ব্যাকআপ

তথ্য শুধু এই ফোনে থাকে। অ্যাপ আনইনস্টল করলে, "Clear data" করলে বা ফোন হারালে তথ্য মুছে যাবে।
নিয়মিত **গ্রাহক তালিকা → ব্যাকআপ নিন** চেপে ফাইলটা Google Drive বা WhatsApp এ রেখে দিন।
নতুন ফোনে **ব্যাকআপ থেকে ফিরিয়ে আনুন** চেপে ওই ফাইল বাছলে সব ফিরে আসবে।

## অ্যাপের অংশ

- `app/src/main/assets/index.html` — পুরো অ্যাপ (হিসাব, ফর্ম, তালিকা)
- `app/src/main/java/.../MainActivity.java` — অ্যাপটাকে ফোনে চালায়, রশিদ ও ব্যাকআপ শেয়ার করে
- প্রতি মাসের লাভ ফর্মে বদলানো যায় (শুরুতে ৳১,০০০)
